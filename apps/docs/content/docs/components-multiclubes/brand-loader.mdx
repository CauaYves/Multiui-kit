As animações ficam no `@multiclubes/ui/styles.css`, que o projeto já importa com o tema.

## Usage

```tsx
import { BrandLoader } from "@multiclubes/ui/components/brand-loader"
```

```tsx
<BrandLoader />
```

## Como funciona

- **O "m" se desenha:** o símbolo da marca em traço único aparece desenhado em 2,5 s e fica; os pontos continuam quicando, um depois do outro.
- **Acessível:** o componente tem `role="status"` e um rótulo para leitores de tela (`label`, padrão "Carregando"). Com movimento reduzido, o "m" aparece pronto e os pontos ficam parados.
- **Só CSS:** as animações são do kit, sem biblioteca de animação.

## Em laço

Para esperas longas, `loop` desenha o "m", segura e apaga, sem parar.

<ComponentPreview name="brand-loader-loop" />

## Cores e tamanho

O traço usa `--brand-loader-stroke` (padrão: `highlight`) e os pontos `--brand-loader-dot-1` a `--brand-loader-dot-4`. O tamanho vem do `className` (`size-20` por padrão).

<ComponentPreview name="brand-loader-colors" />

## API Reference

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `loop` | `boolean` | `false` | Desenha o "m" em laço, em vez de uma vez só. |
| `label` | `string` | `"Carregando"` | Texto para leitores de tela. |
